# CinePirataria 🏴‍☠️

Descrição: Site de filmes piratas com catálogo variado, busca por título e player integrado. Projeto feito só pra estudo, sem fins lucrativos.

## Uso

1. Acesse o site pelo navegador
2. Busque o filme pelo nome na barra de pesquisa
3. Clique no filme desejado
4. Escolha a qualidade e aperte play

## Aviso

Este projeto é apenas para fins educacionais. Não hospedamos nenhum arquivo, apenas indexamos links públicos.
